## الاختبارات

- اختبارات Node الآلية للمدخلات وHTTP والأخطاء والكاش والتحليل والصلاحيات: 24 حالة متوقعة ضمن tests/core.test.ts؛ راجع نتيجة التشغيل النهائية في GitHub Actions.
- اختبار مصدر حي: skipped لأن LIVE_TEST_USERNAME وبيانات اعتماد المصدر غير متوفرة.
- tests/browser-check.mjs يغطي desktop وAndroid المحاكى و320px، الأخطاء واللغة وتقليل الحركة ونتائج null/zero وتقرير قواعد وPDF وانقطاع الشبكة، لكنه **لم يعمل** لأن تنزيل Chromium فشل بملف ناقص. لا تعتبر وجود ملف الاختبار دليلاً على نجاحه.
- حالات الحساب الخاص وغير الموجود والخالي من المنشورات وفشل المصدر والمهلة مختبرة بعينات اختبار محلية فقط.
- يلزم قبل الإنتاج: اختبار مصدر مخول حي، Google/email login/logout، عزل مستخدمين على DB حقيقية، سياسات RLS، PDF، Android/iPhone، اتصال Pages بالـBackend المنشور.

## الأدوات

Ponytail ومهارة Agent Skills incremental-implementation استُخدما. Graphify متاح لكنه غير صالح للعمل في هذه الجلسة لغياب workspace، حتى طلب قائمة workspaces رفضه المزود. OmniRoute غير متاح كخدمة مهيأة ولم يُستخدم. 12ui CLI ثُبّت لكن توليد التصميم توقف عند طلب تسجيل الدخول؛ لم تُشترَ/تُستلم تصميمات ولم يُعتمد ناتج منه. استُخدمت الخلفية والمكونات المناسبة من المشروع الموجود مع تصحيح الواجهة الفعلية.
